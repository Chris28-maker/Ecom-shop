Ecom Shop - Shopify E-Commerce Theme

Description

Ecom Shop is a custom Shopify e-commerce theme built for the Online Store 2.0 platform. It translates a Figma design into a fully responsive, user-friendly online store, featuring dynamic content management, accessible UI components, and optimized performance.

The theme provides a complete shopping experience with product browsing, collection filtering, cart management, and a seamless checkout flow — all while maintaining high design fidelity and cross-device responsiveness.

Tech Stack

- Templating: Shopify Liquid (Online Store 2.0 compliant)
- Frontend: HTML, CSS (responsive media queries), vanilla JavaScript
- Platform: Shopify-hosted environment with Sections, Blocks, and Schema settings
- APIs & Extensibility: Shopify Storefront API, Admin API, and optional app integrations

Features

- Layout & Structure: Theme shell with header/footer groups and a password page
- Page Templates: Product, Collection, Cart, Blog, Article, Account, and Authentication pages
- Reusable Sections: Header & navigation, hero banners, product grids, newsletter CTAs, footer & legal sections
- UI Components & Snippets: Cart drawer UI, product variant picker, search & filtering, image galleries & modals
- Cart Experience: Drawer-style cart, cart notification, quantity popover, and quick-add functionality
- Interactivity: Product hover effects, quick-add buttons, predictive search, and collapsible content
- Localization: Multi-language support across 30+ locales
- Performance: Lazy loading, asset minification, and accessibility (ARIA controls) compliant with Shopify standards

Theme Structure

assets/           CSS, JavaScript, images, and SVGs
config/           Theme settings (settings_data.json, settings_schema.json)
layout/           Theme layout files (theme.liquid, password.liquid)
locales/          Translation files (30+ languages)
sections/         Reusable theme sections (55+ sections)
snippets/         Modular Liquid snippets (37+ snippets)
templates/        Page templates (JSON & Liquid)
  customers/     Customer account templates

Setup

1. Clone this repository
2. Upload the theme to a Shopify development store using the Shopify CLI or the admin interface
3. Configure sections and blocks through the Shopify theme editor
